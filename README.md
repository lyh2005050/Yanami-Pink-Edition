## 特性
- 🌸 全APP粉色主题（浅粉背景 + 热粉按钮 + 深粉文字）
- 💗 粉色渐变窗口背景
- 👧 樱花少女图标
- ☀️ 强制浅色模式
- 📱 基于 Yanami v1.1.0 反编译修改

## 安装
1. **先卸载旧版 Yanami**（签名不同，无法覆盖安装）
2. 安装本APK
3. 添加你的 Komari 服务器地址
