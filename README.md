## 特性
- 🌸 全APP粉色主题（浅粉背景 + 热粉按钮 + 深粉文字）
- 💗 粉色渐变窗口背景
- 👧 樱花少女图标
- ☀️ 强制浅色模式
- 📱 基于 Yanami v1.1.0 反编译修改

## 原项目完整功能
Yanami 原项目具有以下完整功能，本修改版全部保留：

- ✅ 多实例管理 — 添加、编辑、切换多个 Komari 服务器
- ✅ 三种认证模式 — 密码、API Key、游客模式
- ✅ 实时节点列表 — WebSocket 实时推送（CPU/内存/磁盘/网络）
- ✅ 节点详情面板 — 负载历史图表、Ping 延迟趋势、服务器信息
- ✅ SSH 终端 — 基于 termux 的完整终端，支持特殊键和字体调整
- ✅ 桌面小组件 — 节点概览、刷新、更新间隔配置
- ✅ 平板横屏布局 — 自适应大屏，NavigationRail + 多列 + 分屏
- ✅ 多语言支持 — 中文（默认）、英文、日文
- ✅ 主题系统 — Material You 动态色 + 6种预设配色 + 深浅模式
